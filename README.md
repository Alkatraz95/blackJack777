## Описание:

PythonProject555 — это консольное приложение на Python для обработки
банковских операций.

## Модули:

1. **masks** — маскирует номер карты и номер счёта.
   - Реализует логику скрытия средней части номера (формат `XXXX XX** **** XXXX` для карт и `**XXXX` для счетов).
   - Содержит валидацию входных данных (проверка длины, формата, типа).
2. **widget** — унифицированный интерфейс для маскирования данных и нормализации даты.
   - Автоматически определяет тип входной строки (карта или счёт) и применяет соответствующую маску.
   - Корректирует дату из ISO-формата в формат `DD.MM.YYYY`.
3. **processing** — обработка списка транзакций.
   - Фильтрует словари по значению статуса (например, `executed`, `canceled`).
   - Сортирует транзакции по дате в порядке убывания.
   - Обрабатывает краевые случаи (пустой список, отсутствующие ключи, неверный формат даты).
4. **generators** — модуль для ленивой генерации данных.
   - Использует конструкцию `yield` для возврата итератора.
   - Генерирует номера банковских карт в заданном диапазоне.
   - Фильтрует транзакции по валюте.
5. **decorators** — модуль декораторов.
   - Содержит декоратор `log`, который логирует начало и конец выполнения функции, а также время её работы.
   - Поддерживает необязательный аргумент `filename` для перенаправления логов в файл или вывода в консоль.
6. **utils** — вспомогательные функции и работа с данными.
   - Читает файл с транзакциями в формате JSON и возвращает список словарей. При ошибке чтения возвращает пустой список.
   - Реализует конвертацию валюты (USD, EUR, RUB, BYN) с использованием фиксированных курсов для стабильности тестов.
   - Результат конвертации округляется до 2 знаков после запятой.
7. **currency** — модуль для конвертации валют (в текущей реализации логика интегрирована в `utils` для детерминированности тестов, но структура модуля подготовлена для подключения внешнего API).
   - Принимает словарь с транзакцией.
## Использование:

1. Для использования модуля **masks** нужно подать в функции номер карты
   или номер счёта.
2. Для использования модуля **widget** нужно подать в функции строку
   с номером карты или счёта, а также дату.
3. Для использования модуля **processing** нужно подать в функции список
   словарей с данными.
4. Для использования модуля **generators** нужно подать в функции список
   словарей с данными, а также диапазон для генерации номеров карт.
5. Для использования модуля **decorators** декоратор `log` принимает
   необязательный аргумент `filename`, который определяет, куда будут
   записываться логи (в файл или в консоль).
6. Для использования модуля **utils** нужно подать в функции путь к
   JSON-файлу с транзакциями.
7. Для использования модуля **currency** нужно подать в функции словарь
   с транзакцией. Для доступа к API ключ указывается в файле `.env`.
