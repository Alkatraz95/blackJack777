## Описание:

PythonProject555 — это консольное приложение на Python для обработки
банковских операций.

## Модули:

1. **masks** — маскирует номер карты и номер счёта.
2. **widget** — маскирует номер карты или номер счёта в зависимости от ввода
   и корректирует дату.
3. **processing** — фильтрует словари по значению и сортирует по убыванию даты.
4. **generators** — принимает список словарей на вход и возвращает итератор:
   использует yield для генерации значений по запросу. Реализован генератор
   банковских карт.
5. **decorators** — модуль для размещения декораторов, включая декоратор
   логирования `log`.
6. **utils** — читает файл с транзакциями в формате JSON и возвращает
   список словарей. При ошибке чтения возвращает пустой список.
7. **currency** — конвертирует сумму транзакции из иностранной валюты
   (USD, EUR) в рубли через внешний API. Ключ API хранится в файле `.env`.

## Использование:

1. Для использования модуля **masks** нужно подать в функции номер карты
   или номер счёта.
2. Для использования модуля **widget** нужно подать в функции строку
   с номером карты или счёта, а также дату.
3. Для использования модуля **processing** нужно подать в функции список
   словарей с данными.
4. Для использования модуля **generators** нужно подать в функции список
   словарей с данными, а также диапазон для генерации номеров карт.
5. Для использования модуля **decorators** декоратор `log` принимает
   необязательный аргумент `filename`, который определяет, куда будут
   записываться логи (в файл или в консоль).
6. Для использования модуля **utils** нужно подать в функции путь к
   JSON-файлу с транзакциями.
7. Для использования модуля **currency** нужно подать в функции словарь
   с транзакцией. Для доступа к API ключ указывается в файле `.env`.
